## ▶️ How to Use TwitchDownloader

Using TwitchDownloader is straightforward. Here is how to save videos, clips, and chat:

### Download a Video or Clip

1. Open TwitchDownloader.
2. Find the Twitch video or clip page you want to save.
3. Copy the URL (the web address from your browser’s address bar).
4. Paste the URL into TwitchDownloader’s input box.
5. Choose what you want to download:
   - Full video (VOD)
   - Clip only
   - Chat replay
6. Choose a save location on your computer by clicking the “Browse” button.
7. Click “Download.” The program will save the video or clip to your chosen folder.

---

### Download Chat as Video or Text

1. Paste the Twitch URL of the video you want chat from.
2. Select “Download Chat.”
3. Choose the format:
   - Video overlay with chat replay (a video showing the chat messages as they appeared).
   - Plain text file with chat messages and timestamps.
4. Set the save location.
5. Click “Download Chat.”

## 🛠 Troubleshooting

- **App doesn’t start:** Make sure your OS is up to date. Try running the app as administrator (Windows) or with permissions on macOS/Linux.
- **Download doesn’t work:** Check that the Twitch URL is copied fully. Some videos might be private or deleted.
- **Chat doesn’t sync:** Ensure you downloaded the chat for the correct video and version.
- **Slow downloads:** Check your internet speed. Download size depends on video length and quality.
